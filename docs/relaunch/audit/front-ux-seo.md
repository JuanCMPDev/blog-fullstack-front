# Audit: SEO, performance, accessibility, UX/IA and brand fit
Repo: /home/user/blog-fullstack-front (commit 29e168a, 2026-03-31) | Next 15.3.9, React 19, Tailwind 3, shadcn new-york
Method: static code review plus the `next build` route table. Live site not reachable (egress blocked), so nothing here was measured in a browser; contrast ratios were computed from the CSS tokens. Backend repo (/home/user/blog-fullstack-back) was read only to confirm which endpoints exist.

Severity: P0 = defeats the relaunch goal, fix first. P1 = fix before linking from social profiles. P2 = soon after. P3 = hygiene.
Effort: S under 0.5 day, M 0.5-2 days, L over 2 days.

---------------------------------------------------------------------

## (a) Executive summary

The codebase is technically healthy (tsc exit 0, vitest 12 files / 48 tests pass, lint shows 3 warnings, security headers set, solid shadcn/Radix base, tidy dark/light tokens) but it is positioned and built as something other than what the owner wants to launch.

1. **It reads as a generic tech-news / online-course platform, not as Juan Carlos Muñoz's professional blog.** Root metadata, Hero, Footer, FAQ, Terms and the OG image all say "noticias, cursos, plataforma educativa, equipo editorial, Lo ultimo en tech". The "Sobre mí" page exists but nothing links to it (only the sitemap does). Nav is Inicio / Cursos / Proyectos / Contacto, with Iniciar sesión / Registrarse in the header. There is no "Blog" and no "Sobre mí" in the nav.
2. **Blog posts are not server-rendered.** `/post/[slug]` ships only a skeleton in the HTML; the article, its JSON-LD and the 404 decision happen after hydration + a client fetch. Home, search, projects and courses work the same way. For a site whose main traffic will be links from social profiles and search, this is the biggest SEO and LCP problem. The server already fetches the same post for `generateMetadata` and throws it away.
3. **Share cards will all look the same and partly broken.** Only post pages have their own metadata; every other page inherits one title/description/OG image. There is no `metadataBase` (build warns it falls back to `http://localhost:3000`), no title template, no canonical. The single OG image is a 425 KB PNG that spells the brand "Tecno Espacio.com" and says "Lo ultimo en tech" (no accent).
4. **Referenced files that do not exist**: `/logo.png` (preloaded on every page and used as JSON-LD publisher logo), `/og-image.jpg`, `/placeholder.svg`. JSON-LD BreadcrumbList points at `/blog`, which is not a route. The sitemap contains 4 URLs and zero posts because it calls `posts/sitemap`, an endpoint the backend does not have.
5. **Performance:** shared baseline is 102 kB; `/post/[slug]` is 521 kB first load because the full Prism build (332 language definitions, 774 kB raw / 270 kB gzip in one chunk) is imported for code blocks. Even a static legal page costs 155 kB because the global layout pulls framer-motion (35 kB gz) and the auth/toast stack. Admin-only libs (recharts, Quill) do NOT leak into public routes.
6. **Accessibility:** the mobile menu button, password toggles, user-menu trigger, mobile Save button and About social icons have no accessible name. No skip link, 5 public routes nest `<main>` inside `<main>`, `prefers-reduced-motion` is never honored (typewriter inside the h1, 21 floating icons, infinite gradient/pulse/bounce), and 25 text spots use `text-muted-foreground/30..70` (1.5-2.7:1 contrast). Core tokens pass AA (primary 5.71:1 light, 7.39:1 dark).
7. **Bug with brand impact:** `getAvatarUrl()` falls back to `/profile.jpg`, the owner's selfie, for every user without an avatar. Any commenter or author without a photo will show Juan Carlos's face.

Recommended relaunch shape: single-author blog + portfolio. Keep posts, projects, about, contact, CV, theme toggle. Hide or cut courses/exams, public registration, profiles, likes/saves and the comments-by-account system. Details in (e).
